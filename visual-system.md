# Visual System — Nepal Cinematic Direction

## Core concept

Working title: `Nepal in Layers`.

Visual metaphor:

- Mountains, temples, prayer flags, mist, stone, gold light, and deep shadow layered in 3D depth.

Signature element:

- A mountains-first cinematic hero using real Nepal photography, layered depth, glass UI cards, and `NEPAL` as large translucent background typography.

Status:

- Direction approved in principle. Exact assets and final composition still need user approval before coding.

## Palette draft

Use as planning tokens only:

- `Himalayan Night` — `#05070A`
- `Mist Slate` — `#AEB8B5`
- `Temple Gold` — `#D7A84D`
- `Prayer Red` — `#B8322A`
- `Lumbini Sand` — `#E8D6A8`
- `Snow White` — `#F4F0E8`

Rules:

- Dark base.
- Accent chosen by contrast and image needs, not fixed blindly.
- Gold/red/saffron may be tuned per hero image.
- White text softened, not pure sterile white everywhere.
- Accent color used for CTA, small markers, timeline points, and hover states.

Contrast rule:

- Use whichever accent remains readable over real mountain imagery.
- Body text contrast target: at least 4.5:1.

## Typography direction

Display role:

- Strong uppercase destination lettering for hero and section titles.
- Must feel editorial/cinematic, not default SaaS.

Body role:

- Highly readable sans-serif for descriptive copy.

Utility role:

- Small uppercase captions for place labels, coordinates, or section markers.

Approved mood:

- Elegant editorial.

Font pairing — confirmed:

### Confirmed: Option C — Cinematic Luxury ✅

- Display: `Libre Bodoni`, serif.
- Body/UI: `Inter Tight`, sans-serif.
- Feel: cinematic, sharp, premium.

Rejected options:

- ~~Option A — Cormorant Garamond + Satoshi~~
- ~~Option B — Fraunces + Manrope~~

Rules:

- Keep max 2 main font families.
- Use large `NEPAL` background word like sample.
- Body line length target: 55–75 characters desktop, 35–45 mobile.
- Font choice: **locked**.

## Image treatment

Use:

- Large scenic background images.
- Dark gradient overlays.
- Soft mist layers.
- Subtle grain.
- Rounded glass cards.
- Parallax depth.

Avoid:

- Random stock-photo collage without visual unity.
- Oversaturated HDR mountains.
- AI-looking fake landmarks unless user explicitly approves generated imagery.

Asset rule:

- Every place photo must be real.
- Every real place photo must be user-provided, licensed, or sourced with verified rights before shipping.
- No AI-generated final place imagery.

## Layout language

Use:

- Wide hero frame.
- Floating glass nav.
- Compact highlight cards.
- Large section titles.
- Asymmetric place blocks.
- Timeline or route-like vertical sequence only if content truly has order.

Do not use:

- Hotel/flight/transport “included” cards.
- Pricing cards.
- Package comparison tables.
