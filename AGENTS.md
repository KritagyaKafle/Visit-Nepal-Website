# Visit Nepal — Agent Instructions

## Project

Cinematic promotional website for visiting Nepal, built with Astro.

## Development

Start the dev server:

```
astro dev
```

Build for production:

```
astro build
```

Preview production build:

```
astro preview
```

## Project Planning Files

Read these before making any changes:

- `design-brief.md` — project scope and direction.
- `content-information-architecture.md` — page structure and sections.
- `visual-system.md` — colors, typography, image treatment.
- `motion-interaction-plan.md` — animations and scroll behavior.
- `3d-assets-plan.md` — 3D approach and asset rules.
- `component-sources-plan.md` — external component libraries.
- `implementation-rules.md` — technical constraints and build path.
- `feedback-questions.md` — open questions for user.
- `review-process.md` — reviewer subagent mandate.
- `skills.md` — design and build skill definitions.

## Strict Rules

- No hotel, transport, flight, or booking features.
- No fake facts, statistics, or itineraries.
- No AI-generated place imagery.
- Real images only.
- CTA text: `Discover Nepal` (never `Book`).
- Run subagent review after every change per `review-process.md`.
