# Design Brief — Visit Nepal Promotional Website

## Project goal

Create an advanced, smooth, cinematic promotional website for visiting Nepal.

This is not a booking/service marketplace.

## Scope

In scope:

- Destination promotion.
- Cultural and natural atmosphere.
- Visual storytelling.
- Nepal landmark/place highlights.
- Smooth scroll-based experience.
- Clean modern layout inspired by `sample.png`.

Out of scope:

- Hotel booking.
- Transport booking.
- Flight booking.
- Tour package sales.
- Price tables.
- Service marketplace features.
- Fake itinerary claims unless user approves them.

## Sample image observations

Status:

- `sample.png` was visually inspected.
- It is a style reference only.
- Its Japan content, `Book` CTA, hotel/flight/transfer/service cards, and trip-package structure must not be copied.

From `sample.png`:

- Tall single-page landing layout.
- Full-screen cinematic destination hero.
- Huge translucent country word behind scene.
- Glassy top navigation.
- Small vertical social icons.
- Overlay cards for quick highlights.
- Dark section transition after hero.
- Large uppercase section titles with horizontal rules.
- Image-backed content with heavy dark overlays.
- Timeline-style journey section.
- Frosted glass form block near bottom.
- Footer repeats navigation in low-contrast glass style.

Allowed sample traits:

- Cinematic photo-backed hero.
- Big translucent destination word.
- Glass UI.
- Dark overlays.
- Smooth one-page flow.

Banned sample traits:

- `Book` button.
- Hotels.
- Flights.
- Transfers.
- Package itinerary promises.

## Nepal adaptation

Replace Japan theme with Nepal tourism theme.

Confirmed direction from user:

- Style: mixed real photos + 3D glass/depth UI.
- Hero focus: mountains first.
- Typography mood: elegant editorial.
- Main CTA: `Discover Nepal`.
- Contact section: yes.
- Image rule: real images only.
- Place count: 8 popular places with extraordinary appearance.

Confirmed required places:

- Pashupatinath.
- Swayambhu.
- Lumbini.

Recommended candidate places for user approval:

- Everest / Khumbu region.
- Annapurna / Machapuchare view.
- Pokhara / Phewa Lake.
- Bhaktapur Durbar Square.
- Chitwan.

Important: do not invent historical, religious, distance, pricing, itinerary, or UNESCO facts without user approval or verified source.

## Target feel

Keywords:

- Cinematic.
- 3D creative.
- Clean.
- Smooth.
- Premium.
- Cultural.
- Calm but memorable.
- Travel-promotion focused.
- Real-photo cinematic.
- 3D glass/depth UI layered over imagery.

Avoid:

- Overloaded tourism brochure.
- Generic mountain-card grid.
- Fake service promises.
- Busy animation everywhere.
- Cheap neon travel aesthetic.

## Required user inputs before coding

- Final site name/logo text.
- Approval or replacement of the 8-place candidate list.
- Preferred language: English only or English + Nepali.
- Contact form fields.
- Source of real photographs/assets.
